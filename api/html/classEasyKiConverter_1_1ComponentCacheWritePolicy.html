校验写入请求是否对应当前缓存上下文。

判断异步缓存写入是否仍属于有效缓存上下文。

参数
currentGeneration当前缓存目录代次
expectedGeneration写入请求捕获的代次，零表示不启用代次校验
tombstones缓存删除屏蔽状态注册表
componentId元器件编号
返回
当前请求可以继续写入时返回 true

同步写入请求的 expectedGeneration 为零时保持原有的无条件放行行为。

参数
currentGeneration当前缓存代次。
expectedGeneration写入请求携带的缓存代次。
tombstones当前缓存删除标记集合。
componentId元器件编号。
