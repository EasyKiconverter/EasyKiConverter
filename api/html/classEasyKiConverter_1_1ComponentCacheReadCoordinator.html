详细描述

协调元器件缓存的完整性校验和磁盘读取。

该协调器只负责读取路径的锁边界、元数据校验和 CAD 数据检查；一级缓存、 写入策略、目录迁移和公开信号仍由 ComponentCacheService 负责。
