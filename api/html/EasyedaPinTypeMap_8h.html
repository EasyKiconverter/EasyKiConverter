EasyEDA 引脚类型和方向到 IR 枚举的映射

EasyEDA 使用整数编码引脚类型（0-4）和旋转角度（0/90/180/270）。 此映射表将其转换为 IR 的 PinElectricalType 和 PinDirection 枚举。

映射来源：

  • SymbolData.h 中的 PinType 枚举（0=Unspecified, 1=Input, 2=Output, 3=Bidirectional, 4=Power）
  • 导出器中的旋转角度处理逻辑

在文件 EasyedaPinTypeMap.h 中定义.
