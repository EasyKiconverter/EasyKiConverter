详细描述

通用符号引脚

替代 SymbolPin 及其子结构体（SymbolPinSettings, SymbolPinDot, SymbolPinPath, SymbolPinName, SymbolPinDotBis, SymbolPinClock）。 所有字段均为解析后的最终值，不再存储原始字符串。

结构分为三层：

  • 几何：position, length, direction
  • 电气语义：electricalType, style
  • 显示控制：display
