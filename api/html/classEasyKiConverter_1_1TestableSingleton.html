详细描述

template<typename T>
class EasyKiConverter::TestableSingleton< T >

Template for testable singleton pattern

Usage: class MyService : public TestableSingleton<MyService> { friend class TestableSingleton<MyService>; MyService() = default; public: void doWork(); };

Testing: MyService::setTestingInstance(new MockMyService()); // run tests MyService::destroyInstance();
