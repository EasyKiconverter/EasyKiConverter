◆ beginBatchUpdate()

void EasyKiConverter::ConfigService::beginBatchUpdate ( )

开始批量更新（抑制 saveConfig 调用）

开始批量配置更新，暂缓重复写入配置文件。

与 endBatchUpdate() 配对使用。在批量更新期间， 所有 setter 不会触发 saveConfig()，而是在 endBatchUpdate() 时统一保存一次。 支持嵌套调用。
