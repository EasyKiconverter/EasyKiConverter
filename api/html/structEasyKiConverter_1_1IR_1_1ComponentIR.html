详细描述

通用组件（顶层聚合）

将符号、封装、3D 模型和元数据聚合为一个完整的组件描述。 所有字段均为 EDA 无关的通用数据。

EasyEDA 特有字段（lcscId、uuid、docType 等）通过 sourceMetadata 传递，导出器按需读取但不依赖其存在。

◆ sourceMetadata

QVariantMap EasyKiConverter::IR::ComponentIR::sourceMetadata

来源特有的元数据键值对

EasyEDA 来源可能包含：lcscId, jlcId, uuid, docType, datastrid, jlcOnSale, supplierPart, supplier, jlcpcbPartClass 等。

Altium 来源可能包含：vaultGuid, itemGuid, revisionGuid 等。

导出器可按需读取，但不应假设这些字段存在。 使用示例：

if (ir.sourceMetadata.contains("lcscId")) {
addProperty("LCSC Part", ir.sourceMetadata["lcscId"].toString());
}
