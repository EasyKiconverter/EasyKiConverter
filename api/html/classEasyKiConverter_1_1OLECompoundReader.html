详细描述

OLE 复合文档 V3 只读解析器

解析 CFB/OLE Structured Storage 文件中的存储树、普通流和迷你流。 该类只负责读取，不会修改输入文件，供 Altium 库校验和后续增量合并使用。

参考：[MS-CFB] Compound File Binary File Format。
