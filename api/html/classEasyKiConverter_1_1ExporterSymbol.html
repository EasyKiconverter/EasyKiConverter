确定符号导出的坐标原点

已按来源逻辑原点归一化的符号必须保持该原点；旧的直接构造 IR 数据没有原点标记时，继续使用几何包围盒中心作为兼容回退。

统一布局符号属性

所有字段共用同一水平锚点，按可见字段在上、隐藏字段在下的顺序垂直排列。

计算 Value 属性锚点

Value 使用主体中心，不复用 EasyEDA 文本的自由坐标和旋转。

归一化越界的图形文本

API 文本坐标可能使用独立画布基准，超出主体边界时将其按可见顺序 放置到主体中心区域；不依赖文本内容进行判断。
