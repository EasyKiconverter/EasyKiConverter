EasyEDA 层 ID → Altium 层编号映射

EasyEDA 和 Altium 共享 Protel/Altium 层编号体系，大部分层 1:1 映射。

层编号对照： 1 = Top Layer, 2-31 = Inner Layers, 32 = Bottom Layer 33 = Top Overlay, 34 = Bottom Overlay 35 = Top Paste, 36 = Bottom Paste 37 = Top Solder Mask, 38 = Bottom Solder Mask 39-54 = Internal Planes 1-16 55 = Drill Guide, 56 = Keepout 57-72 = Mechanical 1-16 73 = Drill Drawing, 74 = Multi Layer
