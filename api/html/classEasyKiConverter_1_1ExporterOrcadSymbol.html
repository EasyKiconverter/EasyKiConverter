详细描述

将统一符号 IR 写入 OrCAD Capture XML 符号库。

输出的是公开 XML 交换格式，不是 Capture 私有二进制 OLB；用户需要在 Capture 中按对应版本执行 XML 导入或转换。封装名称写入 Package 属性， 不在符号 XML 中伪造 PCB 封装几何或三维关联。
