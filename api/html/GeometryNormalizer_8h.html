详细描述

坐标解析和几何归一化工具

从 SymbolDataConverter.h 中提取的纯几何工具函数。 负责：

  • EasyEDA 坐标字符串解析（空格分隔、逗号分隔、SVG 路径）
  • 单位转换（px -> mm, pt -> mm）
  • Y 轴翻转
  • 原点偏移

不涉及任何类型映射或 IR 构建逻辑。

在文件 GeometryNormalizer.h 中定义.
