Altium PcbLib 文件写入器

分层生成 CFB 容器、库级配置、封装目录和强类型图元记录；每一层均保持 自己的长度与索引不变量，避免依赖不可审查的二进制模板。

编码图元标志位

参数
isLocked是否锁定图元
isTentingTop是否覆盖顶层阻焊

isKeepout是否为禁止区图元

根据图元属性生成 Altium 标志字： Bit 2 = Unlocked, Bit 3 = Saved, Bit 5 = TentingTop, Bit 6 = TentingBottom, Bit 9 = Keepout
