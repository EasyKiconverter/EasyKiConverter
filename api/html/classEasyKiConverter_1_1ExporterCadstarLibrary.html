详细描述

将统一 IR 写入可回读的 CADSTAR ASCII 库。

该导出器生成文本交换库，不声称生成 CADSTAR 私有数据库。 符号、封装和 Part 在同一个 .lib 中输出，3D 模型由独立阶段输出。
