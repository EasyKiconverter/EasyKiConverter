详细描述

管理格式导入器注册和输入格式探测。

注册表只负责选择解析器，不负责持有格式专用模型或执行转换。

bool EasyKiConverter::Parser::ImporterRegistry::registerBuiltInImporters ( )

注册当前已实现解析器的内置描述。

注册 Xpedition、Cadstar 和 P-CAD 等当前已有实现的内置导入器。

方法可重复调用；只会补充缺失的内置 ID，不会覆盖调用方注册的描述。

返回
