详细描述

3D模型导出阶段

管理3D模型(Model3D)的并行导出任务。 每个元器件的3D模型导出由Model3DExportWorker执行。

目录结构: <outputPath>/ └── 3dmodels/ ← 3D模型目录 ├── component1.wrl ├── component2.wrl └── ...

使用 TempFileManager 进行临时写入、备份提交和失败回滚。

并发配置:

  • 最大并发数: 2（3D模型文件较大，I/O较慢）
