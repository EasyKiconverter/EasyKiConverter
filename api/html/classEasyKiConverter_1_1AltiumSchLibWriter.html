详细描述

Altium SchLib 文件写入器

将 AltiumSchComponent 列表写入 .SchLib 格式的 OLE 复合文档。

OLE 流结构： Root/ FileHeader — 库头参数 + 元件名称列表 SectionKeys — 元件名到存储键的映射（可选） <SectionKey>/ — 每个元件一个存储区 Data — 所有图元记录 Storage — 嵌入图像数据（可选）

文件索引、组件记录及子图元归属在同一模型上计算，保证 Header 的计数与 Data 流一致。
