EasyEDA 旋转约定：

  • 0 = 向右
  • 90 = 向上（Y 轴翻转后）
  • 180 = 向左
  • 270 = 向下（Y 轴翻转后）

◆ toPinElectricalType()

PinElectricalType EasyKiConverter::IR::EasyedaPinTypeMap::toPinElectricalType ( int  easyedaPinType)

EasyEDA 整数引脚类型 -> PinElectricalType 枚举

参数
easyedaPinTypeEasyEDA 引脚类型整数（0-4）
返回
对应的 PinElectricalType

EasyEDA 引脚类型编码：

  • 0 = Unspecified（未指定）
  • 1 = Input（输入）
  • 2 = Output（输出）
  • 3 = Bidirectional（双向）
  • 4 = Passive（无源）
注解
与现有 PinType 枚举值一一对应，但类型安全。

在文件 EasyedaPinTypeMap.h 第 39 行定义.

引用了 EasyKiConverter::IR::Bidirectional, EasyKiConverter::IR::Input, EasyKiConverter::IR::Output, EasyKiConverter::IR::Power , 以及 EasyKiConverter::IR::Unspecified.

被这些函数引用 EasyKiConverter::IR::toSymbolIR().
