详细描述

导出器工厂类

根据目标 EDA 格式创建对应的导出器实例。 使用工厂模式隔离格式特定的导出器实现， 使服务层无需关心具体的导出格式细节。

独立 WRL/STEP 模型导出器实例，调用方拥有所有权；目标格式未知时返回空指针
注解
使用裸 new 而非 std::make_unique，因为 Exporter3DModel 继承 QObject， 需要将 parent 传递给构造函数以建立 Qt 对象所有权。
WRL/STEP 是独立模型产物，所有目标格式都可以复用该转换器；目标格式的原生模型关联仍由各自封装导出器决定。
