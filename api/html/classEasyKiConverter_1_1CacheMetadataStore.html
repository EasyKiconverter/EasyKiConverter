详细描述

负责元器件缓存元数据的读取、构建、合并和原子写入。

该类不管理缓存目录、不持有缓存服务锁，也不负责缓存生命周期；它只处理 元数据在 ComponentData、JSON 和磁盘文件之间的转换。
