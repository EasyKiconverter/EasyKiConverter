详细描述

通过 Horizon 官方 Python binding 更新并注册 Pool。

该类只负责调用官方 horizon.Pool 和 horizon.PoolManager，不复制 Horizon 的 SQLite schema 或配置文件写入逻辑。解释器默认使用 python3， 也可通过 EASYKICONVERTER_HORIZON_PYTHON 和 EASYKICONVERTER_HORIZON_PYTHONPATH 指定官方运行环境。
