详细描述

管理 GitHub Release 更新检查、缓存和用户提醒策略。

网络请求统一通过 INetworkClient 注入，默认使用项目的 NetworkClient 单例； 测试可以注入 MockNetworkClient，避免访问真实 GitHub 服务。
