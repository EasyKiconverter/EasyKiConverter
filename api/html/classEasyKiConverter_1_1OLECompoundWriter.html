详细描述

OLE 复合文档 V3 写入器

仅支持写入，不支持读取。实现 OLE Structured Storage V3 格式（512 字节扇区）。 用于生成 Altium Designer 可读取的 .SchLib / .PcbLib 文件。

遵循：[MS-CFB] Compound File Binary File Format
