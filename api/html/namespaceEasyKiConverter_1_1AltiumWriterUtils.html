◆ getSectionKey()

QString EasyKiConverter::AltiumWriterUtils::getSectionKey ( const QString &  name)

获取元件的 Section Key（OLE 存储键）

参数
name元件名称
返回
符合 CFB 31 字符限制的安全键名

Altium OLE 复合文档中，每个元件存储在以 SectionKey 命名的存储区中。 本项目在 IR 名称与物理 storage 名称之间建立显式映射：保留常用可读字符， 其余字符归一化，并由 makeUniqueSectionKeys() 按 CFB 的大小写规则消除冲突。

QString key = getSectionKey("Resistor/0402");
// key = "Resistor_0402"
