详细描述

协调缓存根目录切换、迁移和切换后的自修复。

目录切换涉及磁盘写锁、缓存代次、tombstone 和一级缓存失效，统一放在 一个协作者中可以避免公开缓存服务混入目录生命周期细节。

切换缓存根目录并按需迁移旧目录。

在统一锁边界内完成缓存目录切换。

参数
cacheDir新缓存根目录。
migrateExistingCache是否迁移旧目录内容。
error可选的错误信息输出指针。

切换目录会使旧代次写入失效，并清空没有目录归属信息的一级缓存。

参数
cacheDir新缓存根目录。
migrateExistingCache是否迁移旧目录内容。
error可选的错误信息输出指针。
返回
切换成功时返回 true。
