PCB 封装的通用中间表示

替代 FootprintData.h 中的结构体，移除所有 EasyEDA 特有格式：

  • 层 ID 使用 LayerType 枚举（替代 EasyEDA 整数层 ID）
  • 焊盘形状使用 PadShape 枚举（替代原始字符串）
  • 焊盘类型使用 PadType 枚举（替代 holeRadius > 0 推断）
  • 坐标以 QList<QPointF> 存储（替代原始字符串）
  • SVG 路径已解析为几何参数
