详细描述

将统一符号 IR 写入 P-CAD ASCII 原理图库。

符号库使用独立文件名，避免与 PCB .lia 封装库发生覆盖冲突。 封装和三维模型仍由各自导出阶段生成，并通过器件关联字段连接。
