轻量路径安全检查（字符串前缀比较）

适用于 UI 层的快速校验。不解析符号链接，不保证防逃逸。 写入/删除操作请使用 isSafePathCanonical()。

baseDir基准目录路径

强路径安全检查（使用 canonical path）

解析符号链接后再做前缀比较，可防止符号链接逃逸。 适用于写入/删除前的最终校验。要求目标路径或其最近存在父目录已存在。

参数
fullPath目标完整路径
baseDir基准目录路径
返回
如果安全则返回 true
