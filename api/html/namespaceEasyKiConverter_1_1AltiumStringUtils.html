◆ parsePathString()

QList< QPointF > EasyKiConverter::AltiumStringUtils::parsePathString ( const QString &  pathStr)

解析 SVG 路径命令为 QPointF 列表

参数
pathStrSVG 路径字符串（如 "M 0 0 L 100 200 Z"）
返回
从路径中提取的坐标点列表

简化处理：移除所有路径命令字母，提取剩余的数字对。 EasyEDA 的 SymbolPath.paths、FootprintSolidRegion.path 使用 SVG 路径格式。

auto points = parsePathString("M 0 0 L 100 0 L 100 100 Z");
// points = [{0,0}, {100,0}, {100,100}]
