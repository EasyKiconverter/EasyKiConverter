# Privacy Policy

**Last Updated:** March 13, 2026

English Version | [中文版本](PRIVACY_POLICY.md)

## 1. Introduction
EasyKiConverter ("we", "us", or "our") is committed to protecting your privacy. This Privacy Policy explains how we handle information when you use our desktop application.

## 2. Data Collection
**The project does not include telemetry, advertising, or crash-reporting services, and it does not upload user files to the project maintainers' servers.**

- **Local Preferences Only**: The application saves certain user preferences (such as window position, theme settings, or last used options) strictly on your local device. These files are stored locally and are never transmitted to us or any third party.
- **No Telemetry or Profiles**: We do not collect names, email addresses, location data, device identifiers, or other information for building user profiles.
- **No Analytics**: We do not use any third-party analytics or advertising services.

## 3. Internet Usage
When the user performs the corresponding operations, the application uses the shared network client to access EasyEDA/LCSC-related endpoints for component information, preview images, datasheets, and 3D models. Requests may include the component number entered by the user and query parameters required by the endpoint. The application may also access the GitHub Releases API to read release metadata. When the user chooses to update, the application only opens the Release page in the system browser; it does not download, install, or execute update files internally.

User preferences, caches, exported files, and logs remain on the local device. The current repository contains no code that sends telemetry, user files, or crash reports to the project maintainers.

## 4. Third-Party Services
Our app is open-source software licensed under GPL-3.0. We do not integrate any third-party SDKs that collect user data.

## 5. Changes to This Policy
We may update this Privacy Policy from time to time. Any changes will be posted on this page.
