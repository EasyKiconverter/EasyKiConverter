# 隐私政策

**最后更新时间：** 2026年3月13日

[English Version](PRIVACY_POLICY_en.md) | 中文版本

## 1. 引言
EasyKiConverter（"我们"、"我们方"或"我们的"）致力于保护您的隐私。本隐私政策解释了当您使用我们的桌面应用程序时，我们如何处理信息。

## 2. 数据收集
**项目不包含遥测、广告或崩溃上报服务，也不会将用户文件上传到项目维护者的服务器。**

- **仅限本地偏好设置**：应用程序仅将某些用户偏好设置（如窗口位置、主题设置或上次使用的选项）严格保存在您的本地设备上。这些文件存储在本地，绝不会传输给我们或任何第三方。
- **无遥测和个人资料收集**：我们不收集姓名、电子邮件地址、位置数据、设备标识符或任何其他用于建立个人资料的信息。
- **无分析工具**：我们不使用任何第三方分析或广告服务。

## 3. 互联网使用
应用程序在用户执行相应功能时，通过统一网络客户端访问 EasyEDA/LCSC 相关接口以读取元件信息、预览图、数据手册和 3D 模型。请求可能包含用户输入的元件编号及接口所需的查询参数。应用还可访问 GitHub Releases API 读取版本元数据；用户选择更新后，应用仅通过系统浏览器打开 Release 页面，不在软件内部下载、安装或执行更新文件。

用户配置、缓存、导出文件和日志保存在本地设备。当前仓库没有实现向项目维护者发送遥测、用户文件或崩溃报告的代码。

## 4. 第三方服务
我们的应用程序是根据 GPL-3.0 许可证的开源软件。我们不集成任何收集用户数据的第三方 SDK。

## 5. 政策变更
我们可能会不时更新本隐私政策。任何更改都将发布在本页面上。
