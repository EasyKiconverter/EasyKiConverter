## [3.1.15] - Release preparation

### Bug Fixes

- **Network request cancellation and timeout deadlocks**
  - Fix potential self-deadlocks when aborting `QNetworkReply` for a timeout or cancellation while holding the reply mutex.
  - Add regression coverage for cancelling pending requests, timeout aborts, and worker-thread shutdown.

- **Multi-component export temporary-directory lifetime**
  - Fix shared temporary directories being removed too early during parallel export.

### Build and Compatibility

- **Qt and QML build requirements**
  - Align build checks around Qt 6.8 or newer and keep project-provided subdirectory `qmldir` files in use.

### Testing and Quality

- Complete the Doxygen comment format in network regression tests so the comment-policy check passes.
