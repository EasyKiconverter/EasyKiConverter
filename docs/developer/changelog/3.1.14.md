# 更新日志 — v3.1.14

**发布日期**: 2026-10-24

> 详细更新内容请参见 [CHANGELOG.md](../CHANGELOG.md)

## [3.1.14] - 2026-10-24

### 修复

- **Altium SchLib 符号显示模式** ([#227](https://github.com/EasyKiconverter/EasyKiConverter/issues/227))
  - 修复单显示模式符号将引脚、图元和参数错误写入替代显示模式的问题。
  - 保持公共图元、部件归属、内容索引和多部件符号结构不变。

- **KiCad 3D 模型追加与更新** ([#226](https://github.com/EasyKiconverter/EasyKiConverter/issues/226))
  - 修复已有 `manifest.json` 时追加或更新缺失三维模型失败的问题。
  - 合并关联清单时保留未参与本次导出的历史组件和文件记录。
  - 仅将成功生成且实际存在的 WRL/STEP 文件写入本次更新的组件条目。
  - 使用原子文件提交，清单写入失败时保留原清单。

- **Altium 多部件符号布局**
  - 按部件独立计算主体边界、引脚连接点和参数文本位置，避免高引脚数多部件符号互相推动布局。
  - 保留引脚编号、方向、部件归属、公共对象和其他源数据；新增高引脚数多部件回归测试。
  - 自动化测试覆盖等价的 134/131 引脚多部件样例；不同 Altium Designer 版本的实机打开验证仍需在 Windows 环境完成。
