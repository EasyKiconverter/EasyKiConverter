# Changelog — v3.1.14

**Release Date**: 2026-10-24

> For detailed changes, see [CHANGELOG_en.md](../CHANGELOG_en.md)

## [3.1.14] - 2026-10-24

### Bug Fixes

- **Altium SchLib Symbol Display Mode** ([#227](https://github.com/EasyKiconverter/EasyKiConverter/issues/227))
  - Fix single-display-mode symbols being written with an unintended alternate display mode for pins, graphics, and parameters.
  - Preserve common graphics, part ownership, content indexes, and multipart symbol structure.

- **KiCad 3D Model Append and Update** ([#226](https://github.com/EasyKiconverter/EasyKiConverter/issues/226))
  - Fix append and update failures when an existing `manifest.json` is present and a 3D model is missing.
  - Preserve historical components and file records that are not part of the current export when merging the manifest.
  - Record only WRL/STEP files that were generated successfully and actually exist for the current component update.
  - Use atomic file replacement so a manifest write failure preserves the previous manifest.

- **Altium Multipart Symbol Layout**
  - Compute body bounds, pin connection points, and parameter positions independently for each part, preventing high-pin-count multipart symbols from affecting one another.
  - Preserve pin numbers, directions, part ownership, common objects, and other source data; add a high-pin-count multipart regression test.
  - Automated tests cover an equivalent 134/131-pin multipart sample; real opening tests with different Altium Designer versions still require a Windows environment.
