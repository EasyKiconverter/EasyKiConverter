# 更新日志 — v3.1.15

**发布日期**: 待正式 Release

> 本文档记录 v3.1.15 发布准备分支中的变更；正式发布日期以 GitHub Release 为准。

## [3.1.15] - 发布准备

### 修复

- **网络请求取消与超时死锁**
  - 修复请求超时或取消时在互斥锁内中止 `QNetworkReply` 可能导致的自死锁。
  - 增加未完成请求取消、超时中止和线程退出路径的回归覆盖。

- **多器件导出临时目录生命周期**
  - 修复并行导出时共享临时目录被过早删除的问题。

### 构建与兼容性

- **Qt 与 QML 构建约束**
  - 统一 Qt 6.8 及以上的构建检查，并固定使用项目自带的子目录 `qmldir` 文件。

### 测试与质量

- 补齐网络回归测试的 Doxygen 注释格式，满足注释规范检查。
