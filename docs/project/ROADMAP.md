# 项目路线图

本文档区分已发布能力、当前开发分支能力和后续计划，避免将开发中的功能误认为稳定版能力。

## 当前状态

- **最新稳定版本**: v3.1.13（在 v3.1.14 正式 Release 公开前保持不变）
- **发布准备版本**: v3.1.14
- **发布目标提交**: 待 PR #232 合并后，以 `v3.1.14` 分支最终 HEAD 为准。
- **发布分支**: `v3.1.14`
- **当前开发分支**: `master`（源代码版本 3.1.13）
- **开发状态**: 统一中间表示和多目标导出能力持续完善

v3.1.14 的中文/英文更新日志、应用元数据和跨平台 CI 验证已准备完成；正式稳定版本状态以该提交创建的 `v3.1.14` 标签和公开 Release 为准。在标签创建前，不将 v3.1.14 描述为已发布稳定版本。

稳定版目前以 KiCad 导出为主要发布能力。`master` 已包含统一中间表示（IR）、Altium Designer
库导出和 Xpedition ASCII 库导出实现，但这些能力是否包含在稳定安装包中必须以对应 Release
说明为准。
